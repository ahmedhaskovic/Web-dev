# Update the AI log

1. Read `docs/AI_LOG.md`; create it with a `# AI Log` heading if it is missing.
2. Find or add the section for the current milestone.
3. Ask the student which AI tool/model they used, what task it helped with, and the main prompt if those details are not already known.
4. Record the tool, task, prompt, generated work, and what the student kept, changed, or rejected.
5. Ask whether the AI was wrong or produced poor code. Record what was wrong, how the student noticed it, and how it was fixed.
6. Never invent tools, models, prompts, student decisions, mistakes, or fixes. If a detail is unclear, ask.
7. Show the proposed entry and wait for the student's confirmation before saving it.
